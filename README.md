#URL Shortener Service

URL Shortener Service — это микросервис, который позволяет пользователям брать длинные реферальные ссылки в нашем приложении и сокращать их до коротких, удобных для использования.
Это особенно полезно для публикаций в социальных сетях, где длинные ссылки выглядят громоздко и занимают много места.

🧩 Основные функции сервиса

🔗 Сокращение URL-адресов
Пользователь отправляет длинную ссылку на сервер, получает короткую версию и может использовать её где угодно.

💾 Хранение данных в PostgreSQL
Все пары длинных и коротких ссылок сохраняются в базе данных.

⚡ Кэширование с помощью Redis
Повторные запросы на короткие ссылки обрабатываются быстрее за счёт кэширования.

🔁 Переиспользование ресурсов
Реализован планировщик, который очищает и переиспользует ресурсы.

🌐 REST API
Удобный интерфейс для интеграции с другими сервисами и приложениями.

🧵 Многопоточность
Оптимизирована обработка запросов для высокой производительности.

📊 Мониторинг и метрики
Интеграция с Grafana и Prometheus для отслеживания состояния и производительности системы.
